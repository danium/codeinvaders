# Accessibility

Every semantic transition available in the WebGL arena is also represented in
the DOM activity feed and inspector. WebGL failure must not remove session,
task, operation, permission, gap, or replay information.

All controls are native keyboard-operable elements with visible focus and a
logical document order. Status uses text and shape in addition to color. High
contrast is available without erasing state distinctions. Reduced motion
replaces travel, shake, flash, and explosion with immediate state changes while
preserving meaning. Live-region messages are concise and rate-limited so event
storms do not overwhelm assistive technology.

The release check covers keyboard-only use, focus order, accessible names,
contrast, color independence, reduced motion, zoom/responsive layout,
screen-reader landmarks and announcements, and a forced WebGL-disabled journey.
Automated checks supplement rather than replace the documented manual pass.
