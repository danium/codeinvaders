# Governance

CodeInvaders is currently maintained by the repository owner, who is
responsible for releases, security response, protocol stewardship, and final
merge decisions. Code owners review changes to security-sensitive boundaries.

Routine changes use pull requests and the required CI matrix. Material protocol,
privacy, security, compatibility, or product-scope changes require an OpenSpec
proposal and recorded decision before implementation. Release tags are created
only by the protected release workflow from a commit that passed the complete
gate.

As sustained contributors emerge, maintainership may be granted based on
quality, judgment, review participation, and respect for privacy and
noninterference—not commit count alone. Governance changes are proposed and
reviewed like other design decisions.
